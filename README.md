# 🏡 Proyecto: Residencia Inteligente & Domótica

Bienvenido al repositorio central de diseño, planeación financiera e infraestructura tecnológica para la construcción de tu casa inteligente a 3 años.

---

## 🧭 Estructura del Proyecto

```
📁 Proyecto_Casa_Inteligente/
├── 🌐 index.html                                # Dashboard visual interactivo del proyecto
├── 📂 assets/
│   ├── 🎨 css/style.css                         # Estilos y diseño responsivo del dashboard
│   └── ⚡ js/app.js                             # Calculadoras de ahorro, simulación y checklist interactivo
├── 📂 docs/
│   ├── 📄 01_vision_y_cronograma_3_anos.md      # Plan financiero, crédito de terreno y metas anuales
│   ├── 📄 02_dossier_tecnico_obra.md            # Especificaciones para arquitecto y electricista
│   ├── 📄 03_arquitectura_red_y_rack.md         # Diseño de red Cat6, PoE, VLANs y servidor local
│   ├── 📄 04_subsistemas_domoticos.md           # Iluminación, clima, audio, accesos, cisterna y riego
│   └── 📄 05_presupuesto_y_catalogo_equipos.md  # Costos de materiales de obra negra y equipos
└── 📂 planos_y_diagramas/
    └── 📄 README.md                             # Archivos PDF y planos de la casa
```

## 🚀 Cómo usar este proyecto

1. **Abrir el Dashboard Visual:**
   * Haz doble clic en [`index.html`](file:///home/olethros1318/Escritorio/Proyecto_Casa_Inteligente/index.html) para abrir la aplicación web local en tu navegador.
   * Puedes usar la **Calculadora de Metas a 3 Años**, explorar el **Plano Interactivo de Subsistemas** y marcar el **Checklist de Obra**.
2. **Entregar al Arquitecto / Constructor:**
   * Comparte el archivo [`docs/02_dossier_tecnico_obra.md`](file:///home/olethros1318/Escritorio/Proyecto_Casa_Inteligente/docs/02_dossier_tecnico_obra.md) para que integre las tuberías, cajas profundas y cable neutro en los planos oficiales.
3. **Revisar Presupuesto:**
   * Consulta [`docs/05_presupuesto_y_catalogo_equipos.md`](file:///home/olethros1318/Escritorio/Proyecto_Casa_Inteligente/docs/05_presupuesto_y_catalogo_equipos.md) para monitorear costos y cotizaciones.
